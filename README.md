# MHFZ Transmog Builder


## A tool to help you visualize transmogs from Monster Hunter Frontier Z on your hunter.

This project was made to help you imagine transmog armors on your hunter since there are no preview system for transmogs in Monster Hunter Frontier. With this tool, you'll be able to :
- Easily search every transmog available in game
- Try them on your hunter in a single click
- Register transmog mixsets


## How to install the tool

- Go the release section of the project
- Download the latest release
- Extract the projet
- Launch MHFZ-Transmog-Builder.exe

## Future features planned
I've planned to add more features to this tool in the future to help you find more easily the perfect style for your equipement:

- Filters for every armor piece so you can sort them by style, color and much more (in progess, 1/3 of the armor pieces are already filtered)
- Better looking UI
- Change hunter's skin color
- Optimize search time
- Better lighting
- More backgrounds
- Maybe armors that aren't available as transmogs in game

## Known issues
- Some armor pieces might have a wrong texture/opacity
- Switching too fast between a male and a female mixset might display the faces of both characters at the same time
